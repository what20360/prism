## 词条

每个原型保留自己的机制，再抽取不重复词条。威胁值t：闯关为难度−1+房间深度，无尽为√层数，资源1v1为2。第一条概率 `0.28+0.035t`；t≥5时另有35%概率抽第二条。超过1的概率自然表示必有词条，词条数量不用于替代属性成长。

| 词条 | 属性与机制 |
|---|---|
| 树皮 | 格挡+4(1+0.08t)，HP×1.2，移速×0.92，热抗性−20 |
| 迅捷 | 移速×1.25，攻速×1.1 |
| 重甲 | 护甲+25，物理抗性+20，移速×0.9 |
| 雷涌 | 电抗性+60，热抗性−20，攻击改为电伤 |
| 炽热 | 热抗性+60，电抗性−20，攻击改为热伤 |
| 裂核 | 接近玩家时自爆预警，任何真实死亡释放环形弹幕；自爆体自带此条 |

不同条目的数值叠加；同时有雷涌和炽热时，热伤优先，抗性仍叠加。树皮有分段外环，自爆有危险圈和倒计时，激光蓄能有方向线。名称、词条、格挡和抗性可在锁定面板查看。

## 难度与随机生成

- 闯关仍为五层、每层五房及最终Boss；第1档使用基础数量和单波，七档曲线仍见 `balance.md`。新局按种子将约48%的非Boss位置替换为五种普通/精英原型之一，再加词条；基础原型整体增强。格挡额外加 `0.7×(难度−1)×(1+深度/3)`。Boss不被随机替换。出生安全检查、波间预警和只生成一次的房间资源保持有效。
- 无尽原型概率：游荡者30%、炮台16%、游猎18%、自爆16%、核心守卫13%、灼线哨兵7%。参考尺度为HP50、伤害9、护甲15、格挡3、移速185、弹速430、攻速0.8、射程900，再按原型偏置、重尾随机因子和抖动分布。
- 每层参考倍率分别为HP1.18、伤害1.13、护甲1.09、格挡1.08、移速1.012、弹速1.015、攻速1.01、射程1.008的幂。有限层在词条叠加后逐项检查2.5倍参考上界，三项抗性不超过60；开放层不使用层数上界，强度尾部稀有但无设计最大值。零射速原型不因随机成长突然开枪。
- 1–4、6–9等层一次性生成 `4+ceil(2√层数)` 个敌人；第5n层开放传送门，死亡后补刷，奖励乘数仍为 `(1+k/入场数量)^−2`。伤害收入与晶片均受奖励乘数影响。资源1v1使用五种非Boss敌人的词条组合，保持公共怪物/资源数量预算。

## 伤害与击杀掉落

设原始伤害D、固定格挡B、护甲A、穿甲P、对应伤害类型抗性R。每次结算为：

`max(0,D−B) × 100/(100+max(0,A−P)) × 100/(100+max(−80,R))`

护盾先承受剩余伤害，之后扣HP；有效伤害是实际扣掉的盾与HP，溢出是扣尽HP后的余量。完全格挡不发伤害收入、不吸取、不施加状态。核心倍率先提高原始伤害，因此重击能更有效地突破格挡。

电伤施加45tick的80%移速；热伤附加3次燃烧，每20tick一次、原始伤害的15%。燃烧只有一个实例，重复热伤刷新次数并保留较大伤害；不再次点燃，仍经过格挡、护甲和热抗性。1v1普通弹丸无统一受伤无敌帧，怪物接触独立间隔30tick；单人受伤30tick、复活保护120tick继续生效。

持有掘金者/美食家时，每次玩家真实击杀各掉一次对应资源，武器、地雷、归属明确的燃烧均可触发。n级基础晶片为2n；血球为 `n×max(2,玩家最大HP×2.5%)`。零溢出有完整基础保底；价值乘：

`1+0.75log₂(1+减伤后溢出/目标最大HP)`

晶片生成时再乘敌人奖励乘数，拾取时乘一次拾取者收益，公共掉落可被另一玩家拿走。限额1v1不产生额外经济、禁购掉落卡；自爆、复活和同一尸体的后续命中都不能重复发放。房间初始血球/晶片仍只生成一次。

## 主武器与卡片适配

电弧发生器32、激光发射器36，都是单级可出售功能卡，互斥；卖完恢复弹芯枪。功能优先级90/91，电容绕组与聚焦透镜在120，需对应武器。卖掉武器会停用其专精和持续照射，保留专精等级供重装。

| 卡片机制 | 实体弹 | 电弧 | 激光 |
|---|---|---|---|
| 伤害/穿甲 | 单弹 | 每次跳跃 | 每次脉冲 |
| 射程 | 累计移动路程 | 整条分支路径 | 瞬时射线总路径×1.8 |
| 霰弹 | 多方向实体弹 | 多个互异起点 | 多方向射线 |
| 连发 | 同朝向依次发射 | 传导目标数，须有穿透 | 照射时长，离散多次命中 |
| 穿透 | 单位/核心/墙面消耗 | 命中、强化跨跳、剩余增伤 | 单位/核心/墙面消耗，每脉冲重置 |
| 镜面弹射 | 墙面弹射 | 不适用 | 墙面折射 |
| 核心透镜 | 核心命中 | 不适用 | 核心命中 |
| 追踪/悬浮/贯穿推进/裂晶 | 实体弹机制 | 整卡暂停 | 整卡暂停 |
| 弹速 | 实体弹/破片速度 | 瞬发，无弹速 | 瞬发，无弹速 |
| 宽幅弹芯 | 扩大弹体命中半径 | 不适用 | 扩大射线命中宽度 |
| 自动索敌/扳机 | 支持 | 支持 | 支持 |

连发的伤害/射程代价和霰弹的伤害代价适用于能量武器。狙击手存在时，连发/霰弹仍整卡暂停，电弧单起点，激光单线；不存在延后排队补发。无法生效的购买显示具体原因，电弧连发还要求穿透大于当前传导轮数。

电弧分支先选取最多 `min(连发轮数,穿透)` 个可达互异目标，跨跳距离不超过 `220+射程×0.2`。每个目标花1穿透，多余穿透优先为跨跳各支付1，普通伤害保留62%、强化85%；余下每层提高整条分支15%伤害。电容绕组n使基础电伤×(1+0.2n)，两种损失分别除以(1+0.25n)，剩余增伤比例也乘(1+0.25n)。各起点独立预算，全次放电目标去重、不穿墙。

激光每次触发持续12×连发轮数tick，每6tick瞬时结算一次，脉冲伤害为基础伤害×0.7×(1+0.2×聚焦等级)。一次照射承诺执行完毕，松开扳机仍持续至结束，可转动瞄准；照射期间不能开启下一次照射，攻速过高时受照射时长限制。命中核心耗2层、其他目标耗1层；墙面折射另耗1层且须保留1层继续。同一脉冲内不重复打同一目标，不同脉冲正常重复伤害。

## 地雷专精

震荡雷芯24：n级1+n段、每段伤害÷(1+0.45n)，间隔8tick。每段分别扣格挡，只有末段产生一次破片和子雷。爆炸阶段雷体不再接收弹丸伤害，停止移动和减速场。

蜂巢雷芯32：n级每次末段释放2n子雷，继承 `c=0.4+0.35n/(n+3)`。伤害和耐久乘c（HP最低1），半径乘√c（面积同比继承），减速增量乘c，破片数向下取整，继承段数但繁殖等级为0。子雷15秒失效，不占母雷数量；独立上限为当前母雷上限×(2+当前蜂巢等级)，满额替换最早子雷。出售上限卡立即裁剪超额母/子雷；卖完蜂巢撤回子雷，已经放置的母雷也不再繁殖。延时引信每级+16雷体HP和0.25秒引信。

存储与运行预算约束单次能量分支/射线和场上实体（单人2048弹、256雷、256轨迹，联机采用更小预算），避免极端测试构筑阻塞页面；没有新增数值成长卡设计等级上限。主武器外形、瞄准、能量轨迹、弹丸共用按类型/阵营/剩余路径/强度变化的配色，电弧与激光有独立合成音色。

## 验证与测试入口

测试控制可选择固定靶机或指定七种原型、树皮及混合敌群，设置目标HP/护甲/格挡。建议比较相同花费的多弹和重击构筑，并逐项检查电弧跨跳、掩体反射和子雷限额；伤害统计以有效伤害为准。

自动回归覆盖格挡顺序、零伤害无收益、保证掉落及溢出、状态到期、自爆遮挡/唯一死亡弹幕、电弧预算/去重/距离、激光穿墙防护/反射/时长、武器互斥、多段末段收尾、母子雷出售上限、子雷到期、旧schema/实付账目、确定性恢复和双方联网快照。数值仍须结合完整通关与真人1v1反馈调校，理论伤害不能代替命中率。
