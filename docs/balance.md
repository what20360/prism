# PRISM 数值表（Balance）

## v1.21 合作数值

合作1–5人，独立开局200棱晶。每房记录在线人数N，普通怪与每波数量按 `ceil(原数量×(1+0.7×(N−1)))`；每波运行预算200，Boss不复制，按每增加1人追加2名护卫。无尽初始群同倍率，奖励衰减以该房生成时的人数快照计算，中途加入/掉线不改已生成的预算。

复活300 tick（5秒），暂停不读秒，复活50%最大生命、护盾0、保护120 tick。离线席位不参与团灭判定、资源分配或读秒，重连保留原构筑和生命状态。全在线成员倒地即失败，无法靠继续按钮复活。

均分资源基础总量不增加；贡献规则默认基础池25%均分、75%按对目标的有效伤害占比，无贡献则全部均分。晶片分给所有在线者（包括倒地），各自只乘一次棱晶收益；血球仅治疗存活且需要治疗的成员，过量部分重新分配。击杀归属规则仅锁定击杀掉落，环境资源公开；归属者离线后释放。自由拾取不分享。命中经济按对应规则分配，购买退款不分享。

## v1.20 当前覆盖规则

价格 `round(C×1.5^(L−1))`，自动索敌/自动扳机首价各50；旧实付价由冻结v1–v4表保留。霰弹伤害÷(1+0.4n)；贯穿推进每次补射程200n。激光脉冲倍率0.3，聚焦伤害×(1+0.1n)，散射仍÷(1+0.2n)。狙击手每级伤害/射程×2，弹速×(1+2n)，一弹上限；连发/霰弹在狙击手下分别改为伤害×(1+0.1n)，原弹数和代价暂停，仍可买卖。

电弧每跳0.8R，起点射程R。每起点独立无环树，连发控制最深传递层，穿透控制树的节点总数。每命中耗1穿透；同深度原始伤害相同。多余穿透可从浅到深整层强化，每层按该层分叉数付费；不足整层时余量增伤。保持绕组衰减系数，伤害依传递深度乘衰减。

盘丝洞通道300，中央510×510，下侧右边入口。基础巢母HP3600、甲65、格挡4、移速150、弹伤14、弹速320、扇形13弹；三波间隔60tick、轮次600tick。雷伤26、雷HP70，工蛛雷体64/爆炸190/触发110/减速200，巢母雷各半径×1.5，引信72tick，场上最多6。雷库存3、360tick补1，库存全满才派工蛛补雷，工蛛目标在旧位置附近±72变化。

幼蛛最多6，召唤库存6、240tick补1、缺员后120tick间隔释放。半血仅首次补齐，每只扣最大HP/36、最低留1。幼蛛HP=max(16,巢母HP×0.012)、移速×1.3、伤害×0.4；锁敌850、冲刺触发420或半血、仅一次24tick；近115后停步预警36tick，自爆半径150、伤害×2，死亡8颗散弹。工蛛HP=max(24,巢母HP×0.018)、移速×1.15，最多3只、45秒期限。

安全屋1000×700、出口在上部，资源不需长距离跑图。新资源按625/125/25/5/1拆成独立实体；同面值不合并。单次生成仍最多625点，场内预算384（PvP192）颗。旧存档数量字段仍可读取。自动模式只在有效射程内存在可见目标时工作，离开目标后回手动；停止攻击也是护盾脱战回复条件。

关卡集提供折光回廊、交错屏障、四柱工坊、盘丝洞。闯关固定以盘丝洞收尾；无尽第5层起可以抽到盘丝洞，有限层仍检查巢母及随从基础属性上限，开放层保留可跳过与补刷。召唤物只由巢母缓存补充，不加入无尽补怪队列。

## v1.19 武器、概率掉落与敌人

格挡B与护甲A、穿甲P、对应元素抗性R按 `max(0,原始伤害−B) × 100/(100+max(0,A−P)) × 100/(100+max(−80,R))` 结算。电伤减速倍率0.8持续45tick；热伤附加每20tick一次、3次的15%原始伤害燃烧，不叠加多个燃烧实例，重复热伤刷新持续次数，伤害保留较大值；燃烧不再次点燃。

掘金者首价26、美食家24，对应等级n，每击杀的期望资源点数 `p=0.1n+0.1×减伤后溢出+怪物最大HP/1000`，未购买n=0。晶片p先乘敌人奖励倍率，血球不乘。数量为 `min(625, floor(p)+Bernoulli(frac(p)))`；零溢出时仍有基础概率，不保证每次掉落。按625、125、25、5、1贪心拆分，同规格以数量堆叠；晶片拾取时乘一次收益。仅真实击杀触发，自爆不发、尸体不重复；资源1v1公共怪物也适用，原18点基础奖励与额外晶片合并后再封顶625、统一拆分；限额模式禁额外经济。

电弧卡32、激光卡36，单级互斥；电容绕组18（需电弧，基础电伤×(1+0.2n)）、聚焦透镜18（需激光）；震荡雷芯24、蜂巢雷芯32。沿用1.6价格成长与实付60%退款。

电弧每起点最多 `min(连发轮数,穿透)` 个互异目标，首个目标受射程限制，每次传导距离最多 `min(射程,220+射程×0.2)`，全方向选敌且不能穿墙。起点互异，各分支独立穿透/访问集合，不同分支可重复命中同一敌人。锁定优先，其次瞄准方向角差、距离与ID。每命中耗1穿透，多余穿透优先各支付1强化跨跳；普通保留倍率 `1−0.38/(1+0.25×绕组等级)`，强化保留倍率 `1−0.15/(1+0.25×绕组等级)`。最终剩余穿透使整条分支伤害乘 `1+0.15×剩余×(1+0.25×绕组等级)`。

激光射程为最终射程×1.8；单次脉冲伤害为最终伤害×0.7×(1+0.2×聚焦等级)，间隔6tick、每次攻击持续12×连发轮数tick，期间不能开启下一次攻击。霰弹增加射线，相邻散射角为 `0.12/(1+0.2×聚焦等级)` 弧度；每条射线的每个脉冲重置穿透预算，核心命中仍需/消耗2穿透。墙面折射额外耗1穿透，保留至少1层继续。

延时引信每级雷体生命+16、引爆延迟+0.25秒。多段地雷为1+n段，每段雷伤÷(1+0.45n)，间隔8tick。蜂巢每母雷释放2n子雷，继承系数 `0.4+0.35n/(n+3)`，伤害/HP乘系数，范围乘平方根，减速增量乘系数，碎片数向下取整；继承段数，不再繁殖，子雷15秒到期。子雷限额为当前母雷上限×(2+n)，满额替换最早子雷。新增实体采用256条能量轨迹、256颗雷的运行预算，属于帧/存储保护，不是卡片等级上限。

敌人原型、词条基础表及各模式生成规则见 [combat-guide.md](combat-guide.md)，与本节共同覆盖下列历史数值。子雷上限随当前母雷上限与蜂巢等级调整，卖掉蜂巢模组撤回子雷，已经放置的母雷也不再生成子雷。

## v1.16 悬浮弹芯

Lv n 弹速 ÷(1+0.3n)，射程 ×(1+0.15n)，在同一优先级100的卡片管线中结算；首价14及原有价格成长不变。Lv1弹速约保留76.9%、射程增加15%；Lv3弹速约保留52.6%、射程增加45%。射程为累计路径长度，与追踪、弹射及其他射程卡组合使用同一机制。

## v1.13 标准 1v1

| 每层均值增长 | HP ×1.18、伤害 ×1.13、护甲 ×1.09、移动速度 ×1.012、弹速 ×1.015、攻速 ×1.01、射程 ×1.008 |
| 开放层补刷 | 死亡后 60 tick 补入新怪；第 k 个补刷新怪奖励倍率 (1+k/入场数量)^−2，入场怪为 1 |
| 奖励倍率范围 | 同时作用于该敌人的伤害/溢出棱晶、掘金者晶片及其造成伤害带来的受伤棱晶；弹丸/地雷保留发射者倍率，伤害、吸血、得分不受削减 |

无尽开放层不对强度使用层数上界，计算只受有限数值表示约束；随机尾部分布的“无界”按理想连续随机数理解。有限层清场/开放层直接离开都没有额外通关奖励。全卡出售返还实付价 60%，前置只在购买时校验。

### 1.1 护甲 → 减伤换算

```
减伤 = 护甲 / (100 + 护甲)
```

| 护甲 | 减伤 |
|---|---|
| 0 | 0% |
| 50 | 33.3% |
| 100 | 50.0% |
| 200 | 66.7% |
| 300 | 75.0% |
| 600 | 85.7% |
| 900 | 90.0% |
| ∞ | → 100%（永不达到） |

- 减伤是**派生值**，不作为独立属性存储。
- 收益天然递减，因此**不需要封顶**，也不会出现无敌。
- 护甲穿透：`有效护甲 = max(0, 护甲 - 穿透)`，再代入上式。

## 5. 棱晶收益（按伤害结算）

### 5.1 结算公式

```
输出收益 = round((实际伤害 + 溢出伤害 × 0.5) × tierRate × chainMultiplier)
受伤收益 = round(敌方来源的减免前伤害 × takenRate)   // takenRate = 0.05
shardGain = 输出收益 + 受伤收益
```

- 收益与**击杀无关**，每点伤害都产生收益。
- 溢出伤害按 **50%** 计入（奖励高爆发与单发高伤害）。
- 内层伤害 ×1.5 已自动转化为更多收益，不再有额外汇率。
- **承伤同样产生收益**，按减免前伤害计算，见 5.6。

### 5.2 敌人等级系数

| 敌人等级 | tierRate（棱晶/伤害） |
|---|---|
| 普通敌人 | 0.10 |
| 精英 / 层守卫 | 0.12 |
| 最终 Boss | 0.05 |
| 召唤物 / 分裂体 | 0.10 |

### 5.3 连杀

`chain = min(2.0, 1 + 0.1 × (n - 1))`，间隔 > 3 秒或掉血中断。

### 5.4 房间奖励

| 项 | 棱晶 |
|---|---|
| 清空房间 | +10 |
| 无伤清空房间 | 额外 +5 |

### 5.5 收入结构估算

| 项 | 估算 |
|---|---|
| 普通房（8 小怪 × 30 HP） | 240 伤害 × 0.10 × 1.4 ≈ **34**（输出） |
| 普通房承伤（约 15 次命中 × 10 减免前伤害） | 150 × 0.05 ≈ **8**（受伤） |
| 守卫房（Warden 220 HP） | 220 × 0.12 × 1.4 ≈ **37** + 承伤约 10 |
| 每层（4 普通 + 1 守卫） | 输出 ≈ 173 + 受伤 ≈ 42 + 清房 45 ≈ **260** |
| 五层合计 | ≈ **1300** |
| 最终 Boss（2000 HP） | 2000 × 0.05 × 1.4 ≈ **140** + 承伤 |

| 项 | 目标 |
|---|---|
| 输出收益占比 | ≥ 50% |
| 受伤收益占比 | ≤ 20% |
| 清房奖励占比 | ≤ 35% |

> 按上表：输出 ≈ 870 / 受伤 ≈ 210 / 清房 ≈ 225（合计约 1305）→ 约 67% : 16% : 17%，符合目标。

### 5.6 受伤收益（takenRate）

| 规则 | 取值 |
|---|---|
| 计算基数 | **减免前**伤害（护甲减伤前、护盾吸收前） |
| 来源限制 | 只计**敌方来源**；自伤（自己的地雷、环境）不计 |
| 无敌帧 | 被无敌帧挡开的命中不计 |
| 护盾吸收 | **计入** |
| 系数 | `takenRate = 0.05`（约为普通敌人 tierRate 的一半） |
| 连杀 | 不乘 `chainMultiplier`；受伤本身会中断连杀 |

## 9. 校准决策记录

### 第一轮

| 议题 | 结论 |
|---|---|
| 射速手感 | 1.8 → **1.2 发/秒**；仍偏快则取 1.0 |
| 地雷清弹过强 | 不削伤害，**优先提高布置冷却**（2 → 3 秒） |
| 地雷「必吃伤害」 | 设计上不是惩罚：范围必须可视化，玩家应绕开 |
| 内层面积 | 20% 合理 |
| 减伤无敌风险 | 允许极端构筑（玩法核心），靠价格 / 怪物 / 卡片数值平衡 |
| 吸血/吸盾 | 允许重度吸血「几乎不躲」，但 Boss 近身硬吃仍会暴毙 |
| 穿透打内层的理解成本 | 相信玩家；但展示必须充分（命中特效、飘字、面板说明） |
| 房间尺寸 | 桌面主流 1920×1080；射程 = 房间宽度 50%；加入墙体，为弹射预留 |

### 第二轮

| 议题 | 结论 |
|---|---|
| 减伤机制 | 引入**护甲值**，`减伤 = 护甲/(100+护甲)`，天然渐近 100% |
| 卡片定价 | 卡片可捆绑其他属性，但**价格只与购买次数有关** |
| 吸盾 | **不与自身减伤挂钩**；改由「护盾上限 = 最大生命 × 系数」约束 |
| 数值溢出 | 不必过度防御，通过价格、怪物数值、卡片数值调节；探索强力方案是核心玩法 |
| 收益来源 | **按伤害而非击杀**；溢出伤害按 50% 计入收益 |

### 第三轮

| 议题 | 结论 |
|---|---|
| 承伤是否产生收益 | **产生**，且按**减免前**伤害计算（`takenRate = 0.05`），使防御构筑具备经济回报 |
| 承伤的边界 | 只计敌方来源；自伤与无敌帧挡开的命中不计；护盾吸收计入 |

### 第四轮

| 议题 | 结论 |
|---|---|
| 实体尺寸 | 玩家与敌人放大到约 **2.2 倍**（玩家半径 18→40，小怪 16→34） |
| 地图与镜头 | 房间放大到 **3200×1800**，视野窗口固定 1920×1080，相机跟随玩家并夹紧在房间内 |
| 射击手感 | 射速 1.2→**0.8**、射程 960→**560**、弹速 900→**700**，让接近与开火时机成为决策 |
| 地雷 | 半径同步放大（本体 30 / 爆炸 200），触发与减速场改为**爆炸半径的 60%（120）**并通过单一比例变量联动 |
| 偏转 | 改为**被动充能偏转**（按速率侧偏，归属不变）+ **主动反弹**（窗口内反向并夺回归属，Lv2 加伤害） |

### 第五轮

| 议题 | 结论 |
|---|---|
| 射速 | 0.8 → **0.7 发/秒**，进一步给「射速卡」留成长空间 |
| 被动偏转 | 从「充能次数」改为**连续力场**：场内敌方子弹每帧受背离玩家的加速度，越近越强（`strength × (1-d/R)²`） |
| 力场参数 | 半径 220、强度 600（圆心处），偏转卡每级 +40 半径 / +150 强度 |
| 主动技能 | 窗口内力场 ×5，并把接触子弹反向回射、归属转为玩家 |

### 第六轮

| 议题 | 结论 |
|---|---|
| 玩家生命 | 100 → **50**：让「挨打」重新变得昂贵，配合护甲/护盾/吸血卡的取舍 |
| 地雷半径 | 触发与减速场 ∈ **爆炸半径 × 0.6（200 → 120）**，两者共用一个比例变量，只调一个数 |
| 地雷上限 | 满 3 颗后继续布置 → **替换最早的一颗**，而不是布置失败（避免"明明按了却没反应"） |
| 界面按键 | 收敛为**单一菜单键 `Esc`**：左侧目录切换帮助 / 按键绑定 / 升级面板 / 角色属性，不再为每个面板新增按键 |
| 卡片信息 | 价格不足不写字，改**价格变色**；每张卡常显「下一级数值 + 前置条件」 |
| 出生点 | 内容锚点重新选点，运行时再加 `resolveSpawnPosition` 兜底，杜绝敌人卡在墙里 |
