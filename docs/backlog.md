# PRISM 后续开发与验收

状态：v1.27，2026-11-06。只记录未完成的工作；实现入口见技术手册，历史变化见独立更新日志。

## 下一轮优先事项

1. **遭遇多样性**：[敌人与关卡方案](design/encounter-roadmap.md)已完成研究，编队/新敌人/目标房尚未实现。建议先做已有敌人的四套主题编队及反重复，再做裂隙突击者和继电站，避免只堆怪物血量和数量。
2. **真机与跨网络调校**：iOS Safari、Android Chrome的小屏横竖屏、三指、锁屏恢复和五人长局；30/100/200ms RTT与抖动/丢线时的预测校正、预警和资源拾取。当前有自动化输入/伤害/真实WebSocket回归，不等于多台真机验收。
3. **复杂房间寻路与性能**：不同碰撞半径、密集追击、螺壳窄路、目标重算；低画质也必须保留敌弹、地雷与危险预警。模拟上千实体、压缩与DOM频繁刷新需实测预算。
4. **同投入流派比较**：持续电弧保持稳定目标DPS，实际击杀/溢出与控制频率有变化；继续比较五类构筑的命中率、经济和通关时间，特别检查高格挡、分叉与高层极端值。

## 后续产品完善

- 购卡前关键属性变化预览、预设同金额对比和更清楚的前置阻塞说明。
- 手柄适配、完整键盘/手柄菜单焦点导航。键位重绑定已实现，不应再作为未开发项。
- 新技能需提供与现有偏转、冲刺、狂暴不同的决策，先调校已有双槽机制。
- 可选第二武器/武器切换需要重新评估玩法与界面；当前四种武器通过互斥卡选择，不承诺旧草案的Q切换。
- 更多Boss与关卡集；每日种子/挑战可后置，避免取代基础关卡多样性。

## 服务器与技术维护

- 服务器地址/房间目录/固定ID/权限/重连/日志/终端命令已实现；旧WebRTC和TURN方案已移除，不再列作当前联机依赖。
- 公网跨运营商部署、WSS证书/反向代理、吞吐与断网恢复需多设备验证。GitHub Pages只托管游戏静态文件，权威服务器需自行运行。
- 进一步降低高层差量同步与压缩成本；本地预测只优化显示，不能掩盖服务器负载和网络延迟。
- 长期无尽、超大存档、配额、未知卡片/版本的严格迁移；不能通过忽略错误吞掉账目或重新生成资源。
- 浮点确定性仍限于当前JavaScript实现；跨语言移植需要单独验证。
- 可视关卡编辑器/数据化Mod为远期，不在当前已交付范围。

每次恢复先核对main、requirements/balance与相关技术分册，再选择一个可验收的切片。已完成的功能从待办移除，禁止把旧猜测写回游戏帮助。
