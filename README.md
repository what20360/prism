## 它是什么

你可以探索 5 层地牢并挑战 Boss，也可以输入世界种子进入无尽模式，用一把枪和地雷清场、攒棱晶、随时加点变强。

几个与众不同的点：

- **收益按伤害结算，不按击杀**。打得多、打得准、挨得住，都会变成资源；溢出的伤害也半额计入。
- **护甲不是减伤百分比**，而是 `减伤 = 护甲/(100+护甲)`，永远逼近但到不了 100%。
- **升级是卡片**：每张卡有自己的价格函数与机制函数，购买后按优先级复合成最终属性。价格只与购买次数有关，因此可以规划。
- **子弹之间互不碰撞**。清弹只有两条路：地雷爆炸、偏转/反射。
- **玩家与「类玩家敌人」是同一个 `Actor`**，差别只有控制器与能不能加点。

## 开发命令

```bash
npm install        # 安装开发依赖
npm run dev        # 启动开发服务器（http://localhost:5173）
npm run build      # 类型检查 + 生产构建
npm test           # 单元测试（含确定性与 core 隔离检查）
npm run lint       # 代码检查
```

操作：`WASD` / 方向键移动，`E` 放置地雷（满 3 颗后自动替换最早的一颗），`J` / `K` 使用装备的两个主动技能，**`Esc` 打开菜单**（暂停；左侧切换帮助 / 按键绑定 / 升级面板 / 角色属性 / 设置），`R` 在结束画面重开。

启动进入主菜单，可开始闯关、输入种子开始无尽探索、测试构筑或查看帮助与设置。暂停菜单和结算页均可返回主菜单；未结束的局可继续，世界在主菜单期间冻结。选择新的模式会替换当前局。设置保存在当前浏览器；闯关与无尽进度自动保存，刷新后在主菜单点击“载入自动存档”恢复。

测试模式支持静态靶机 / 敌人演练、开阔 / 掩体场地、目标数量 / 生命 / 护甲、可选无敌与自由购卡。升级面板可直接设定非负整数等级（成长卡不限等级，纯开关仅解锁一次，可绕过前置）；测试控制提供总伤害、近 3 秒 / 平均 DPS、恢复和重置操作。测试构筑与闯关相互独立。

开局为**手动瞄准 + 手动射击**：鼠标指向目标，按住左键开火。购买「自动索敌」或「自动扳机」可分别解锁自动操作，设置页可暂时关闭；新局需要重新购买。全部卡片均可逐级出售；前置只限制购买，卖出不会撤销其他已购卡。出售返还该级实付价格的 60%（向下取整）。

手机浏览器自动显示双摇杆：左侧移动，右侧按住开火并拖动瞄准，另有地雷、偏转和菜单按钮。设置页也可强制显示触控按钮。角色周围的青 / 紫 / 金色弧环分别表示射击 / 偏转 / 地雷冷却，高速冷却会隐藏对应环。

49 张卡片支持连发 × 霰弹、追踪、悬浮弹芯飞剑、消耗穿透的弹射、手榴弹、破片、掉落物和风险姿态等组合。数值、价格与描述由函数及共享参数生成。音乐与音效在第一次点击、触摸或按键后启用，可独立静音。房间需要走进去才会开始刷怪，右上角小地图显示当前房间、出口与敌人。

## 开发约定

1. **`core/` 不许出现 `document` / `window` / `canvas` / `fetch`**，由 ESLint 与结构测试强制。
2. **一个伤害入口**：所有伤害必须经过 `core/systems/damage.ts`，禁止旁路扣血。
3. **确定性**：逻辑层不读墙钟、不用 `Math.random`，随机一律走 `core/rng`。
4. **内容即数据**：加敌人/卡片/关卡只改 `content/`，不动 `core/`。
5. 新增玩法规则前，先在 `requirements.md` 里写清楚，再写代码。

## 已知开放问题

见 [requirements.md 第 12.2 节](docs/requirements.md)。当前 24 条，每条都带默认值与阻塞的里程碑。


操作与组合：桌面右键点击敌人固定锁定，右键空白取消；触屏点击敌人固定、点击空白取消；无手动目标时沿攻击方向选择可见目标，锁定框与目标信息卡持续显示。自动瞄准和追踪弹共用目标，但锁定本身不会免费开启自动瞄准。

在菜单“主动技能”页可将偏转、狂暴、冲刺中的两个装入 J/K 槽位；换装保留冷却、卸下结束效果。地雷使用除法减速倍率，三个半径分别升级。狙击手以“同时仅 1 颗自有子弹”为代价，霰弹和破片也受限；携带狙击手时连发整张卡暂停（含伤害与射程代价），不等待空位补发，卖完狙击手后恢复连发。

购买页展示数字优先级，数值越小越先生效；最终生命比例在 1000 阶段计算。分类支持折叠，帮助页提供分章目录与完整规则。手动瞄准采用当前 tick 的相机坐标，避免静止鼠标下连续移动产生方向抖动。


离线单文件构建：运行 `npm run build:offline`，输出 `dist-offline/PRISM_offline.html`。该文件内置代码、样式和程序化音频，可在 Chrome / Edge 等桌面浏览器直接打开，无需服务器或资源目录。离线版与在线版使用相同游戏入口；音乐在首次交互后启用。追踪卡附带射程 ÷(1 + 0.20 × 等级) 的代价。

追踪初速为最终弹速的 20%，加速至 100%，Lv1 转速 1.6 弧度/秒；狙击手 Lv1 弹速 ×3，不另扣转速，高速自然增大转弯半径。“悬浮弹芯”按弹速 ÷(1 + 0.6 × 等级) 降速，配合追踪与射程/穿透/弹幕形成飞剑构筑。射程始终按累计飞行路径扣减，转弯与弹射均消耗路程，同等射程的慢弹存在更久。


无尽模式：输入数字或文字种子，同种子与输入可复现，重开保留种子。1–4、6–9 等清场层只在进入时生成一批敌人，数量随层数增长，并逐属性检查强度上界；清场开启下一层。每 5 层的开放层直接开放传送门，可跳过战斗，死亡怪会持续补刷，强度没有层数上界、强敌更稀有；第 k 个补刷的奖励倍率为 (1+k/入场数量)^−2，防止原地刷钱。怪物主要战斗数值的均值随层数指数增长。

清场没有额外奖励。血球和晶片在进入房间时随机生成一次，保留到拾取或切房。购买“磁吸核心”后可自动吸取范围内资源，设置开关跨刷新保存；关闭仍能接触拾取，满生命不消耗血球。

“贯穿推进”在每次穿过单位且仍有穿透时增加速度和射程，追踪或弹射回来的弹丸可以再次伤害同一目标；持续重叠不重复结算。子弹与拖尾随剩余射程比例变色、变暗，补充射程会恢复部分光效。


## 种子闯关与七档难度

主菜单可选1–7档难度，输入世界种子或点击随机，开局200棱晶。第1档保留原来的敌人数值、数量和单波规则；第2–7档根据难度与房间深度提高生命、伤害、护甲、移动/弹速、攻速、每波数量与波数。第7档“绝境”面向熟练玩家，后期多波强敌形成高压挑战。

同种子/难度生成相同布局与波次。清完一波后有1.5秒出生位置预警，所有波次结束才开放出口；最终Boss仅在最后一波。房间血球/晶片仍只在入场生成一次。种子、难度、波次与刷新倒计时均可保存，重开保留种子/难度并重新发放开局预算；旧存档保持原内容。

## 存档与升级预设

主菜单与暂停菜单的“存档”页提供自动槽与三个手动槽。每 10 秒以及暂停、返回主页、页面隐藏时尝试自动保存，手动槽独立保留。读取后暂停，继续即可恢复血量、卡片账目、冷却、子弹、地雷、房间资源、随机状态与无尽补刷队列。测试场与实时对战不写入单人进度。

已有存档可重命名，名字写入JSON及导出文件名。覆盖保存/导入保留目标槽原名，导入空槽沿用文件中的名称。每个槽可导出 JSON，导入到手动槽后再读取；也可直接“导出当前进度”，不依赖浏览器存储是否可用。文件上限 2 MiB，未知版本、无效属性、重复实体编号和未知卡片会被拒绝，原数据保留。清理网站数据会删除本地保存，文件可用于备份和转移设备。

“预设”或“构筑与预购”页保存命名流派的有序购卡列表、收藏卡片和快捷购买方式，并独立导入/导出 `prism-build` JSON。列表允许重复卡片，例如伤害 → 射程 → 攻速 → 伤害，可逐项移动或移除。载入保持原顺序，已有等级跳过，缺钱或缺前置时等待。卡片属性结算优先级不改变购买顺序。旧版预设文件仍可导入，五格快捷栏转换为收藏。

快捷购买有两种方式：「收藏卡片」有独立分类和屏幕边缘展开列表；「流派提示」在下一项可购买时出现在屏幕右侧，点击购买，开启自动购买则提示满三秒后购买。暂停、倒计时、不可购买和收藏方式下不会自动消费。不再绑定数字购卡快捷键。队列随单人存档保存，联机经济模式也可使用预设和预购。

## 真人联网 1v1

两位玩家各用自己的浏览器：一人“创建对局”发送邀请代码，另一人粘贴邀请并“生成回应代码”，将回应发回房主；房主粘贴并“连接玩家”。连接后显示房主选择的规则：

| 模式 | 初始条件与经济 |
|---|---|
| 固定装备 | 相同标准枪、地雷、偏转与冲刺，不能购买升级 |
| 限额构筑 | 每回合各 600 棱晶，自选构筑，无额外收入、资源或怪物 |
| 资源争夺 | 每回合各 600 棱晶，每 10 秒各加 15；随机刷新资源与对双方敌对的怪物 |

两种经济模式各自独立购买、出售、换装和预购。准备后锁定，双方准备进入 3 秒倒计时；战斗中仍可购买，菜单不暂停。下一回合交换出场侧、重置构筑和余额，保留购卡列表。先赢两回合获胜，每回合 120 秒，超时比较生命比例，平局重赛；支持再战与认输。

浏览器通过 WebRTC 数据通道直连，房主运行权威模拟，客机只发送操作；基础网络辅助采用 STUN，没有配置 TURN 中继或匹配服务器。因此部分校园网、公司网和移动网络可能无法直连。双方应保持游戏页面前台；断线结束当前连接，可重新配对。联机菜单不暂停，单人已购构筑和存档不会带入对战；预设只是付费购买计划。
