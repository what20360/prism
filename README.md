# PRISM

一款 2D 俯视角、几何抽象风的地牢 Roguelike 射击游戏：**局内成长、无局外养成**。

私有在线测试：[PRISM](https://prism-what20360.what20360.chatgpt.site)。开发任务完成后，源码与站点一起更新；发布与版本核对流程见 [docs/deployment.md](docs/deployment.md)。

| 项目 | 状态 |
|---|---|
| 当前阶段 | **M4 地牢结构完成**；主菜单、独立测试场、方向锁定、双技能槽与 53 张构筑卡 |
| 可运行版本 | `npm run dev`：主菜单选择闯关或测试模式 |
| 平台 | Web 优先（浏览器直接运行） |

## 它是什么

你进入一座 5 层地牢，用一把枪和地雷清房间、攒棱晶、随时加点变强，最后挑战 Boss。

几个与众不同的点：

- **收益按伤害结算，不按击杀**。打得多、打得准、挨得住，都会变成资源；溢出的伤害也半额计入。
- **护甲不是减伤百分比**，而是 `减伤 = 护甲/(100+护甲)`，永远逼近但到不了 100%。
- **升级是卡片**：每张卡有自己的价格函数与机制函数，购买后按优先级复合成最终属性。价格只与购买次数有关，因此可以规划。
- **子弹之间互不碰撞**。清弹只有两条路：地雷爆炸、偏转/反射。
- **玩家与「类玩家敌人」是同一个 `Actor`**，差别只有控制器与能不能加点。

## 技术栈

| 项 | 选择 |
|---|---|
| 语言 | TypeScript（`strict`） |
| 构建 | Vite |
| 渲染 | Canvas2D（封装在 `render/`，可替换为 WebGL） |
| 测试 | Vitest（单测 + 确定性回放 + 结构测试） |
| 运行时依赖 | **零** |
| 音频 | WebAudio 程序化音效与循环背景音乐，无音频文件 |

选型理由见 [ADR-0001](docs/adr/0001-tech-stack.md)。

## 目录结构

```
src/
  core/       纯逻辑（无 DOM、确定性）
  content/    内容数据与卡片函数
  render/     渲染器（只读快照）
  input/      设备适配
  audio/      程序化音效与背景音乐
  ui/         面板与 HUD

  storage/    本地配置

docs/         设计文档
tests/        单测与回放回归
```

## 开发命令

```bash
npm install        # 安装开发依赖
npm run dev        # 启动开发服务器（http://localhost:5173）
npm run build      # 类型检查 + 生产构建
npm test           # 单元测试（含确定性与 core 隔离检查）
npm run lint       # 代码检查
```

操作：`WASD` / 方向键移动，`E` 放置地雷（满 3 颗后自动替换最早的一颗），`J` / `K` 使用装备的两个主动技能，**`Esc` 打开菜单**（暂停；左侧切换帮助 / 按键绑定 / 升级面板 / 角色属性 / 设置），`R` 在结束画面重开。

启动进入主菜单，可开始闯关、测试构筑或查看帮助与设置。暂停菜单和结算页均可返回主菜单；未结束的局可继续，世界在主菜单期间冻结。选择开始闯关或测试模式会替换当前局。设置保存在当前浏览器；刷新不保留局内进度。

测试模式支持静态靶机 / 敌人演练、开阔 / 掩体场地、目标数量 / 生命 / 护甲、可选无敌与自由购卡。升级面板可直接设定非负整数等级（成长卡不限等级，纯开关仅解锁一次，可绕过前置）；测试控制提供总伤害、近 3 秒 / 平均 DPS、恢复和重置操作。测试构筑与闯关相互独立。

开局为**手动瞄准 + 手动射击**：鼠标指向目标，按住左键开火。购买「自动索敌」或「自动扳机」可分别解锁自动操作，设置页可暂时关闭；新局需要重新购买。操控卡与三种射击姿态卡可以出售，返还该级实付价格的 60%（向下取整）。

手机浏览器自动显示双摇杆：左侧移动，右侧按住开火并拖动瞄准，另有地雷、偏转和菜单按钮。设置页也可强制显示触控按钮。角色周围的青 / 紫 / 金色弧环分别表示射击 / 偏转 / 地雷冷却，高速冷却会隐藏对应环。

53 张卡片支持连发 × 霰弹、追踪、悬浮弹芯飞剑、消耗穿透的弹射、手榴弹、破片、掉落物和风险姿态等组合。数值、价格与描述由函数及共享参数生成。音乐与音效在第一次点击、触摸或按键后启用，可独立静音。房间需要走进去才会开始刷怪，右上角小地图显示当前房间、出口与敌人。

## 开发约定

1. **`core/` 不许出现 `document` / `window` / `canvas` / `fetch`**，由 ESLint 与结构测试强制。
2. **一个伤害入口**：所有伤害必须经过 `core/systems/damage.ts`，禁止旁路扣血。
3. **确定性**：逻辑层不读墙钟、不用 `Math.random`，随机一律走 `core/rng`。
4. **内容即数据**：加敌人/卡片/关卡只改 `content/`，不动 `core/`。
5. 新增玩法规则前，先在 `requirements.md` 里写清楚，再写代码。

## 已知开放问题

见 [requirements.md 第 12.2 节](docs/requirements.md)。当前 24 条，每条都带默认值与阻塞的里程碑。


操作与组合：桌面右键点击敌人固定锁定，右键空白取消；触屏点击敌人固定、点击空白取消；无手动目标时沿攻击方向选择可见目标，锁定框与目标信息卡持续显示。自动瞄准和追踪弹共用目标，但锁定本身不会免费开启自动瞄准。

在菜单“主动技能”页可将偏转、狂暴、冲刺中的两个装入 J/K 槽位；换装保留冷却、卸下结束效果。地雷使用除法减速倍率，三个半径分别升级。狙击手以“同时仅 1 颗自有子弹”为代价，连发、霰弹和破片同样受限。

购买页展示数字优先级，数值越小越先生效；最终生命比例在 1000 阶段计算。分类支持折叠，帮助页提供分章目录与完整规则。手动瞄准采用当前 tick 的相机坐标，避免静止鼠标下连续移动产生方向抖动。


离线单文件构建：运行 `npm run build:offline`，输出 `dist-offline/PRISM_offline.html`。该文件内置代码、样式和程序化音频，可在 Chrome / Edge 等桌面浏览器直接打开，无需服务器或资源目录。离线版与在线版使用相同游戏入口；音乐在首次交互后启用。追踪卡附带射程 ÷(1 + 0.20 × 等级) 的代价。

追踪初速为最终弹速的 20%，加速至 100%，Lv1 转速 0.75 弧度/秒；狙击手 Lv1 弹速 ×3，不另扣转速，高速自然增大转弯半径。“悬浮弹芯”按弹速 ÷(1 + 0.6 × 等级) 降速，配合追踪与射程/穿透/弹幕形成飞剑构筑。射程始终按累计飞行路径扣减，转弯与弹射均消耗路程，同等射程的慢弹存在更久。
